# Web3 防骗工具箱 v2

> 基于《价值互联网产业应用蓝皮书（2025）》蒸馏的 **10 个识别器整合版**，一个技能覆盖全部场景。

---

## 🎯 一句话

**别人讲概念，我们给尺子。**

---

## 📦 这是什么

本仓库包含一个统一技能 `web3-defense-toolbox`，整合了原先分散的 10 个独立识别器：

| 模块 | 功能 |
|------|------|
| S1 概念辨析器 | 区分通证化/代币化/RWA 等概念层级 |
| S2 合规红线检查 | 划定境内能做/不能做边界 |
| S3 三类模式判别 | 判断原生型/产业变革型/链改型 |
| S4 W-ABCD 真假识别 | 五要素扫描真伪、识别资金盘 |
| S5 贡献分配设计 | 多元贡献计量与公平分润 |
| S6 共建社区运营 | 消费即投资的事业共同体 |
| S7 风险评估反例 | 三层体检 + 三大爆雷原型 |
| S8 RWA 落地路径 | 端到端路线图（A→J 十环节） |
| S9 OPC 个体清单 | 一人公司/数字游民轻创业路径 |
| S10 香港沙盒路径 | 跨境融资合规通道设计 |

## 🚀 安装

```bash
git clone https://github.com/63619990/web3-defense-toolbox
cp -r web3-bluebook-skills/skills/web3-defense-toolbox ~/.workbuddy/skills/
```

或在 WorkBuddy 中搜索 slug：`web3-defense-toolbox` 一键安装。

---

## 📖 使用方法

### 评估一个可疑项目
```
S4 W-ABCD 识别 → S2 合规检查 → S7 风险评估
```

### 规划一个 RWA 项目
```
S3 模式判别 → S8 落地路径 → S5 贡献设计 → S6 社区运营
```

### 个人轻创业
```
S9 OPC 清单 → S2 合规检查 → S5 分润设计
```
